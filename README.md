# 🎵 Very Atractive Synth

**Tu estudio musical, sin complicaciones.** Crea canciones, graba tu voz, mezcla pistas y experimenta con efectos desde el navegador. No necesitas saber producción musical para empezar.

## ✨ ¿Qué puedes hacer?

- 🎙️ **Grabar tu voz:** elige tu micrófono, escucha la entrada y graba sobre una base musical.
- 🥁 **Crear una base:** explora ritmos originales de pop, house, trap, lo-fi y otros estilos.
- 🎚️ **Mezclar pistas:** controla volumen, silencio, solo, efectos y mezcla final.
- 🎬 **Editar como capas:** mueve, recorta, divide y duplica fragmentos; ajusta su velocidad y haz zoom en el tiempo.
- 🔁 **Crear loops:** repite segmentos de una pista sin detener las demás.
- 🪐 **Flow Studio:** conecta y desconecta pistas como nodos; arrastra efectos y observa sus conexiones animadas.
- 🎤 **Transformar voces:** prueba afinación experimental, eco, reverb, distorsión y personajes de voz.
- 🎼 **Practicar notas:** visualiza DO–RE–MI mientras cantas y ajusta partes de una grabación.
- 💾 **Guardar y exportar:** conserva proyectos editables y descarga mezclas o sesiones en WAV.

## 🚀 Cómo empezar

1. **Elige un ritmo** o importa tu propio audio.
2. **Graba una voz** y arrastra efectos a tus pistas.
3. **Edita, escucha y exporta** tu canción.

### 💻 Ejecutar en tu computador

```bash
git clone https://github.com/pyro-nicolini/veryAtractiveSynth.git
cd veryAtractiveSynth
git switch DesignPhase
npm start
```

Abre **http://127.0.0.1:4173** en tu navegador.

> 🔒 **Privado y local:** los audios se procesan en tu dispositivo, sin subir tus grabaciones a un servidor.
>
> 🧪 **En desarrollo:** la aplicación funcional está en la rama **[DesignPhase](https://github.com/pyro-nicolini/veryAtractiveSynth/tree/DesignPhase)**. La afinación y algunos efectos siguen siendo experimentales; faltan pruebas completas con micrófonos y dispositivos reales.
